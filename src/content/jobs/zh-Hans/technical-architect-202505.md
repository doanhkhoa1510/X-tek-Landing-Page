## 岗位职责

- 与客户方架构师一起参与架构设计，兼顾可扩展性、性能、安全性和易维护性，并搭建开发环境。
- 将应用的架构设计转化为框架。
- 为开发与支持团队提供深入的技术指导和实操领导，确保与项目目标保持一致。
- 主持代码评审、设计讨论和技术规划会议，推动持续改进。
- 管理开发过程，确保遵循设计和编码规范，完整实现应用需求，高效且正确地落地各项技术，并实现高水平的可维护性和可扩展性。
- 为开发和缺陷修复提供支持。响应用户反馈的问题，排查技术故障，并及时给出解决方案。
- 排查并诊断软件缺陷，找出根本原因并实施有效修复。
- 与设计师、产品经理和其他开发人员等跨职能团队协作，交付高质量的技术方案。

## 任职要求

- 计算机科学、工程或相关专业本科学历。
- IT 行业 7 年以上相关经验，其中至少 2 年担任技术架构师。
- 技术功底扎实，熟悉 OOP 与 SOA 原则、设计模式，以及遵循敏捷方法的软件开发行业最佳实践。
- 在移动应用和企业级应用方面有担任技术架构师的成功经验，并展现出指导开发团队、处理日常事务的能力。
- 在 React、.NET 框架、Azure Application Services、Azure Integration Services 和 Azure SQL 开发方面经验丰富，能够开发企业级应用。
- 有 Azure LLM、LangGraph 经验者优先。
- 分析与故障排查能力强。
- 能够在快节奏、多变的环境中高效工作。
- 具备出色的人际沟通能力和英语听说读写能力，能够与客户、开发人员、质量保证人员、领域专家和架构师等各类人员高效协作。
