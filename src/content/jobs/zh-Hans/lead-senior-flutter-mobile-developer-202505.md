## 岗位职责

- 研究项目需求、解决方案架构和现有源代码（如有）。
- 设计并开发适用于 iOS 和 Android 的 Flutter 应用，确保其高性能、稳定且可扩展。
- 维护并改进现有代码库，提升其性能、稳定性和可扩展性。
- 与后端开发人员协作，确保与 RESTful API 无缝集成。
- 与跨职能团队协作，定义、设计并实现新功能。
- 排查并诊断软件缺陷，找出根本原因并实施有效修复。

## 任职要求

- 计算机科学、工程或相关专业本科学历。
- 能够在敏捷开发环境中工作。
- 3 年以上使用 Flutter 为 iOS 和 Android 开发复杂、可投入生产的应用的经验。
- 深入理解 Dart 和 Flutter，掌握 Flutter 中的状态管理方案（如 Provider、Riverpod、BLoC）。
- 了解移动端 UI 设计原则、模式和最佳实践。
- 具有使用第三方库和 API 的经验。
- 具有编写单元测试和集成测试的经验。
- 有使用 Jira、Slack、Git 和 AzureDevOps 等现代工具经验者优先。
- 英语听说读写能力良好者优先。

**Flutter 移动端技术负责人（Technical Lead）岗位**另需满足以下职责与要求：
- 2 年以上技术负责人（Technical Lead）经验。
- 具备带领并指导开发团队的能力。
